# LE PROBLÈME

Chaque année, des millions de personnes vivent :

* une rupture ;
* un divorce ;
* une séparation ;
* une relation ambiguë ;
* une relation toxique ;
* une période de non-contact.

Ces personnes sont souvent :

* perdues ;
* impulsives ;
* anxieuses ;
* obsédées par les messages.

Elles prennent souvent de mauvaises décisions.

Elles envoient trop de messages.

Réagissent trop vite.

Interprètent mal les réponses.

Se mettent dans une position de dépendance émotionnelle.

Le produit doit les aider à retrouver de la lucidité.

# IA

L'IA doit donner l'impression de connaître parfaitement la relation.

Elle doit pouvoir répondre naturellement à des questions comme :

Pourquoi répond-elle comme ça ?

Que montre notre historique ?

Compare avec le mois dernier.

Résume notre histoire.

Analyse cette capture.

Prépare une réponse.

Dois-je répondre maintenant ?

Elle doit expliquer son raisonnement.

Toujours distinguer :

* faits ;
* hypothèses ;
* limites.
